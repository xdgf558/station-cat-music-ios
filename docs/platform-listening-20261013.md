网站改版后，用户确认 iOS 客户端也改为音乐平台跳转优先。本批调整 App 的公开作品浏览与入口，不继续把原生完整播放服务接入作为当前产品主线，也不启用正式账号、同步、订阅或发布。

代码基线为已合并 PR #14 的 `f766a9497bb0b5ac25a32bd5bfee4e237fda1c75`。网站核对基线为 `d37439748366ac395ec6404cff372ce9acf69c8d`；其生产页面已经采用外部平台收听优先的发布模型。开发使用独立工作树，保留其他网站后台正在编辑的文件。

## 产品行为

发现页展示网站已公开的主推与精选，曲库展示公开作品并支持本机搜索。点击作品打开新的详情页，显示封面、艺名、简介、故事和已核验的音乐平台入口。平台顺序来自网站配置，不根据设备、IP 或浏览器猜测偏好；无可用链接时显示待公开、暂不可用或地域限制状态，不生成替代地址。

平台按钮交给系统打开已验证的 HTTPS 链接。系统拒绝打开时，详情页提供原链接和复制操作；错误回调受打开操作编号、歌曲身份及详情代次保护，迟到结果不能覆盖其他作品。分享使用当前网站作品链接。只有网站当前公开 DTO 存在有效试听配置时才显示前往网站试听入口，App 本身不请求试听或完整音频。

原有“我的”一级入口与二级页面结构保留，本机收藏仍可增删并从收藏页打开同一作品详情。平台模式不显示迷你播放器、播放进度、队列、会员解锁或新增离线保存入口，也不把一次外链点击记作实际收听事件。已有历史记录和账号资料不因此清空；当前公开目录未包含的作品不会被冒充成可用歌曲。

目录与推荐并行读取，任一部分成功后可进入 App，另一部分继续加载。刷新失败保留已有列表并显示可重试错误；详情失败不暴露旧平台按钮，提供重试和网站链接复制。语言、作品选择、账号作用域及任务代次继续用于拒绝迟到结果。

## 独立公开 API 客户端

`PlatformMusicAPI` 实现 `PlatformMusicProviding`，只读取 `https://wwwstationcat.org/api/station/content` 下的公开元数据：

| 接口 | 用途与参数 |
| --- | --- |
| `GET /tracks` | 曲库；`locale`、`limit=50`、`sort=default` 及服务器返回的原始 `cursor` |
| `GET /home` | 主推与精选配置；仅 `locale` |
| `GET /tracks/:slug` | 当前作品详情；仅 `locale`，使用受限 slug，不把 UUID 当作详情路径 |

四语为 `zh-Hans`、`zh-Hant`、`en`、`ja`。客户端验证 `schemaVersion=1`、响应语言、UUID、slug、网站路径及字段边界。公开响应直接解码网站 DTO，不沿用原生 `APIEnvelope`。`durationMs` 可为空；网站修订号只作为展示结构的版本标识，不能据此推断原音频版本或播放权限。

分页最多十页、五百首。空结果页仍可能携带下一页游标，客户端继续扫描；重复游标、重复歌曲、超预算或非法结果均失败，不把截断列表标为完整目录。推荐按首页主推与精选的配置顺序解析当前详情，清空配置保持空态，不自动补曲库前几首。

HTTP 使用无持久缓存的临时 URLSession，不携带 Cookie、Bearer 或请求正文，拒绝重定向。请求与资源超时均为五秒，流式正文上限为 256 KiB。成功响应还必须是 JSON 且最终 URL 与请求一致，HTML、跳转、错误状态或超限正文不能当作目录。新增响应头与最终 URL 信息保留原 `HTTPResult` 初始化兼容性，没有放宽既有认证请求的判断。

封面和歌词地址仅接受网站受控的相对 asset UUID 路径；封面使用 `size=display` 派生图，复用现有受限图片加载器。详情返回的歌词地址仅作为公开元数据，不因此自动请求歌词正文。公开客户端没有音频、原生能力、登录、播放授权、离线许可或个人资料库写接口。

## 外链边界

客户端重新验证平台 DTO，仅保留 `live`、唯一合法链接 ID、已核验且核验时间不在未来的条目。允许的 provider 与 HTTPS 主机为：

| 平台 | 允许主机 |
| --- | --- |
| 网易云音乐 | `music.163.com`、`y.music.163.com` |
| 汽水音乐 | `music.douyin.com`、`qishui.douyin.com` |
| Apple Music | `music.apple.com` |
| YouTube | `www.youtube.com`、`music.youtube.com`、`youtu.be` |
| Spotify | `open.spotify.com` |

拒绝非 HTTPS、错误或伪装主机、URL 凭据、非标准端口、根路径、登录/认证/重定向路径、控制字符及凭据/跳转目标查询参数。不接受任意 App scheme。网易云只额外兼容精确的 `https://music.163.com/#/song?id=<正整数>` 形式，并规范化为 `/song?id=...`；其他 fragment 不接受。

这项检查验证地址形状与网站登记状态，不证明第三方歌曲已发行、用户拥有第三方会员或平台在该设备上必定成功播放。系统打开成功也不等于已经听到歌曲；本机 UI 测试的拒绝打开场景不向第三方发送请求。

## 本机数据与旧缓存

`Track.release` 为可选 Codable 字段，旧歌曲 JSON 缺少该字段仍可读取；个人资料库继续按环境与账号隔离并保存歌曲 ID。没有迁移、覆盖或删除旧收藏、隐私保护状态、操作日志和 Keychain 凭据。平台模式不建立远端个人同步服务，也不把账号级资料复制到游客作用域。

旧离线文件保留原命名空间。`StationLegacyOfflineOrigin` 与原生认证独立，当前只接受既有隔离 Staging origin `https://station-cat-music-r2.yehao1105.workers.dev`；它用于定位本机缓存，不是平台模式的网络目的地。`LegacyOfflineManagementTransport` 对全部请求返回 `networkDisabled`，不申请许可或下载字节。

缓存管理可查看既有文件及占用，并由用户明确删除单首或清空；不能播放或新增保存。平台目录不会调用旧缓存 reconcile，不会因为歌曲投影为不可播放而删除旧音频，也不会把缓存装入播放器。未知文件与其他作用域不是本批清理对象。保留文件不意味着延长原许可或承诺继续离线播放。

## 配置和默认关闭状态

公开作品接入新增独立的 `STATION_PUBLIC_RELEASES_ENABLED` 与 `STATION_PUBLIC_RELEASE_ORIGIN`，分别进入 Info.plist 的 `StationPublicReleasesEnabled`、`StationPublicReleaseOrigin`。Development、Staging、Production 必须显式 `YES` 且 origin 精确等于 `https://wwwstationcat.org` 才能读取真实公开目录；非法环境、别名、错误地址或缺项继续关闭。它不依赖原生认证 profile，也不能扩大原生 capability。

提交的四种配置均保持这个新开关为 `NO`、公开 origin 为空。Mock 默认采用打包的公开作品夹具，不建立真实网络连接。原播放器夹具只在 Debug 模拟器测试参数下使用，保留旧测试覆盖；该参数不能在发布包或非 Mock 环境打开原生服务。

原 `STATION_NATIVE_AUTH_ENABLED`、`STATION_NATIVE_MUSIC_ENABLED`、`STATION_PERSONAL_SYNC_ENABLED` 和正式 activation 继续关闭。本批不生成正式关联域文件、不修改 AASA/entitlements、不启用完整销户、不出售订阅，不上传 TestFlight 或 App Store。Development 真实公开目录预览仅使用本机命令行覆盖新公开开关，没有改原生开关或提交该覆盖配置。

新歌曲路径可在 App 已取得公开目录后按受限 slug 定位，原 UUID 链接也可匹配目录。初始化前的有效投递仍保存导航意图；没有对应歌曲时提示不可用。这里只新增客户端解析与选择，不扩大服务器 AASA 路径，也不证明操作系统会将这些新路径投递到 App。

## 2026-10-14：版本封面缓存配套候选

用户随后明确要求首次加载后能够直接复用图片缓存。本批新增可选的公开 `coverCacheVersion` 字段，iOS仅接受有对应封面地址的64位小写十六进制指纹，把它附在受控小图URL的 `v` 参数中。卡片和display尺寸各自按完整URL缓存，换版本自动使用新键；旧目录没有此字段时继续使用旧地址，不凭客户端意愿忽略原来的max-age=0策略。
