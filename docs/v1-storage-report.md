# v1.0 收尾第一批：缓存与本机存储预算

日期：2026-09-20。目标是先上架不售卖订阅的 v1.0。基线为已合并的 iOS #7 / 网站 #177；本批不等于整个 R1 或 M5 发布验收完成。

## 实现

列表、歌曲详情和系统 Now Playing 现在复用同一个 ArtworkLoader。它在独立 actor 上完成下载、磁盘 I/O、ImageIO 解码；SwiftUI 不再使用未受此预算控制的 AsyncImage。请求只接受配置主机的 HTTPS，拒绝凭据 URL、非 443 端口与重定向，不发送 Cookie/认证信息。单张下载最多 2 MiB，资源超时五秒，像素尺寸最多 8192 × 8192，输出最大 512px 缩略图。

独立 PublicMusicArtwork-v1 缓存目录存放二进制 plist：仅图片数据、格式版本与有效期，文件名为完整 URL 的 SHA256（保留封面版本查询参数差异），不写原始 URL 或账号身份。缓存最多 150 MiB 编码文件内容、4096 项，按最近使用时间回收；只持久化服务端显式 public / max-age 的图片，尊重 Date / Age、no-store、no-cache、private、Set-Cookie，拒绝所有非空 Vary（当前不实现请求头变体匹配），并将本机复用期上限限制为一天。过期/损坏文件按未命中处理，不在失败时无限重试。目录排除备份、文件使用首次解锁保护。该目录是可重建的公开封面，系统仍可自主回收。

“清理临时缓存”接入共享缓存。代次校验阻止清理前启动的网络请求重新写回图片；不删除收藏、历史、凭据或未上传操作。缓存写入失败不阻断播放。已显示的图片可能继续保留在视图/系统媒体信息内，下一次加载按缓存规则处理。

PersonalMusic 保留每作用域 20 MiB 限制，增加全目录 100 MiB 编码内容和 64 个文件的预算；写入前检查、成功落盘后才发布内存状态。原子替换短暂需要额外一份单文件空间（最多 20 MiB）；这里不把逻辑内容字节数冒充文件系统实际分配块数。普通写入保留每文件 64 KiB 控制空间，该空间以 JSON 尾随空白实际计入文件与总预算。关闭历史、清空、确认基线及回执可消耗当前文件内的预留空间，不能借用其他账号或越过总预算；普通新增数据仍被拒绝，已有超限文件可缩小。不自动驱逐账号文件，不把未同步收藏、隐私指令或游客资料当作缓存。账户切换/保存后释放可从磁盘恢复的非活跃内存副本。损坏/符号链接文件拒绝读写，原始文件保留。

## 业务规则已确认，尚未实施完整销户

用户选择公开评论匿名保留，其余按建议：个人资料继续清理，余额和争议另立处理记录，必要账务凭据最小化保留，不自动退款或清零。网站 policy-draft.json 记录此决定，整体 approved/executionEnabled 仍为 false。

现有 reader_comments.account_id 非空且 CASCADE，匿名保留需要额外迁移与读取适配；现有代码不能直接删账号。完整执行器、财务最小字段/期限、备份恢复屏障、服务端个人库墓碑与幂等记录长期压缩，以及多账号持久文件的显式回收流程仍未完成。此次增加的是预算与保留保护，不将限制写入描述为已完成长期回收。

## PR #8 复审修复：配额恢复和缓存协议

满额恢复采用同一原子文件内的 64 KiB 有界控制预留，普通写入必须保留预留区，限制性/恢复写入可以消耗预留，最多 64 个文件的预留总计 4 MiB，已包含在 100 MiB 内。普通操作仍最多 5000 条，另外最多 16 个位置仅供关闭/清空意图使用。不存在自动删除未上传操作或修改模糊结果请求 ID 的释放空间路径。物理磁盘写入失败仍会显式报错，不宣称配额预留可以解决磁盘本身耗尽；早期未预留的文件在有空间完成普通写入时建立预留，不能无空间凭空增加它。

冷启动先获取真实服务器快照，但只将必要的 confirmedPreferences 和根依赖绑定原子落盘，再上传既有日志；不要求先保存完整显示列表。回执、冲突重绑和日志排空使用控制写入。最终显示快照过大时保留本机日志和已确认隐私状态，synced=false 并报告存储失败；已成功上传的操作不会因显示快照失败而重新加入日志。幂等 ID/载荷、隐私前驱关系与冲突后的限制性意图保留规则未放宽。

缓存改为保守拒绝任何非空 Vary，不持久化缺少/无效 Date、模糊 max-age 或非法 Age 的响应。年龄使用 apparent_age、Age 加响应延迟的较大值，再加下载/解码的驻留时间；耗时来自连续时钟并结合墙钟保守计算。依据 [RFC 9111 §4.1 / §4.2.3](https://www.rfc-editor.org/rfc/rfc9111.html#section-4.2.3)。缓存格式升为 version 2，旧条目没有变体和正确年龄证据，直接失效。
