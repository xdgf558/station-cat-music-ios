# 电台版笔记与主动摘录

本批是客户端界面与本机笔记能力变更，不代表网站隐私页、Apple 问卷或 App Store 候选已发布。

## 新增的本机资料

笔记新增可选 `quote`：用户在已经取得的歌曲歌词中主动点选一行，再选择“摘进笔记”，编辑并保存后，才会将该行保存为笔记的一部分。未点击摘录、只浏览歌曲、切换歌词分段或打开笔记编辑器均不会自动持久化歌词。每条摘录最多 200 个 Swift `Character`、单行，详情页与存储共用校验；家庭、肤色等 emoji ZWJ 字素可保留，换行、双向覆盖和隐藏控制字符仍被拒绝，不静默删除引文字符。摘录必须保留对应的作品 ID 与 slug；删除关联作品时同时移除摘录。

摘录与用户自己写的标题、正文采用相同的本机原子文件、账号与运行环境隔离、设备保护及排除系统备份设置。不上传、不跨设备同步、不保存平台 URL、Cookie、推广来源、整篇服务端歌词或故事。读写失败保留既有文件和当前草稿；清空或切换作用域后，旧编辑器不能恢复已清空的资料。已经保存的摘录属于用户主动保留的笔记内容，清理封面缓存不会删除它，用户可以在笔记中删除或在本机数据管理中清空。

## 数据兼容

沿用 schema 1，`quote` 缺失时解码为 `nil`。旧笔记读取后不被重写，已有文字、日期、主题和版本不变；移除主题时保留笔记及摘录。这里仅保证新版读取既有笔记，不声称旧安装包能保留它不认识的新摘录字段。

标题只保存用户实际输入并去除首尾空白后的文字。未输入标题时存储空字符串，列表按当前语言显示无题；不会将歌词摘录或本地化占位文字写入标题。已有标题可能来自用户手写，不能根据内容猜测并自动清理或改名。

## 交付核对

存储回归覆盖旧 JSON 缺失字段、200 个字符的中文/组合重音/旗帜/ZWJ emoji 摘录与无正文笔记、主题删除、201 字及 LF/CRLF/Unicode 换行和隐藏控制文本拒绝、原子写入失败和重试、关联清除、清空后的迟到草稿、空标题编辑及既有标题不改写。界面回归检查无标题正文保存、编辑、切换语言及搜索，主动摘录仅显示一次；这些是本轮测试范围说明，实际执行结果以交付验证记录为准。界面保留草稿与作用域/epoch 检查；“最近查看”继续是浏览记录，不能当成实际播放证明。

正式发布前应将“用户主动选择的单句歌词可保存在本机笔记”的事实纳入正式版本隐私资料复核；本批不修改网站部署或 Apple 隐私答复。
