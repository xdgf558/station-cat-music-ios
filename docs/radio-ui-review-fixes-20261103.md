# 1.0.8（21）复审修复

本记录对应 PR #24 中首次交付 `e0d69fa` 之后的修复。版本号不变，产品配置和发布授权范围不扩展。旧的验证批次仍单独保留，不用旧提交的 CI 或截图代替本次结果。

## 修复与数据边界

| 复审项 | 当前处理 |
| --- | --- |
| P2：自动生成标题被持久化 | 仅保存用户输入并清理首尾空白后的标题；空标题保存为空，列表按当前语言显示无题。编辑器不填入占位文字，摘录不复制到标题。已有标题不迁移、不猜测清理，避免删除用户手写内容。 |
| P3：摘录长度不一致 | 选取、写入、重开共同使用 `NotebookQuoteInput`，以 200 个 Swift `Character` 为限，覆盖增补汉字及组合 emoji。 |
| P3：可选但无法保存的歌词 | 同一规则拒绝隐藏控制字符、方向标记与换行；详情页禁用不合格摘录并显示具体原因。合法单字素内的 emoji ZWJ 可保存，不静默删除原文。 |
| P3：隐藏 Tab 继续渲染 | 仅创建当前一级页；调频位置、目录搜索/分类、笔记搜索/主题保存在 AppModel，切换账号清理私有搜索。普通滚动及设置子页不跨 Tab 保留。 |
| P3：死分支及重复设置 | 删除 legacyTabs 的不可达平台分支；设置统一为一个有类型的目的地闭包，去掉重复的设置总页，旧资料入口仅在有资料时出现。 |
| P3：弹层强制深色 | 共享弹层继承当前外观；旧原生模式仍由根视图统一使用深色。 |
| P3：繁中/日文字形 | 简中/英文保留 Noto SC；繁中使用原生 TC 字体，日文使用 Hiragino Mincho。本机无 Songti TC，繁中明确回退 PingFang TC 黑体，不声称实测了不存在的衬线字体。 |
| P3：重复创建字体 | 以区域、实际 Dynamic Type 字号及字重作键，用限额 96 项的 NSCache 复用不可变 CTFont；同锁处理并发缺失。没有增加第二份大字体文件。 |
| P3：重复提示框 | 根视图与编辑器使用同一 `radioToast` 修饰器，计时和取消继续由 AppModel 管理，VoiceOver 公告只从 AppModel 发出一次。 |
| P3：重复文案 key | 移除 `notebookTitle` 及额外发现的 `noFavorites` 重复，保留原先最终生效的四语文字。生成器遇到重复时，在写文件前失败；CI 新增实际生成回归。 |
| P3：无用图片 | 删除两个无引用的 imageset：OrbitBackground、StartupBackground（JPEG 合计 329,831 字节）；保留仍在使用的同名 SwiftUI 背景组件。 |
