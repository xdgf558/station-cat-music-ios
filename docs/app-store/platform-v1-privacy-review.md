# 平台版隐私资料审查入口

2026-10-20。本 PR 仅提交文档，为用户选定的正式版 **1.0（13）** 准备隐私材料；没有把该版本的未提交产品改动、签名包、商店截图或上传记录混入本批。当前产品基线仍是合并提交 `940ccb0c515fafd40bd0f1f0986bee71c94458ea` 的 0.1.2（12）。

建议按以下顺序审查：

1. [数据流与保留期限](platform-privacy-draft.md)：客户端本机资料与服务端请求日志的区别、当前数据用途及未验证边界。
2. [问卷逐项草稿](platform-v1-app-privacy.json)：拟披露的数据类型、用途、关联与跟踪判断，尚未保存或发布到 Apple。
3. [四语政策正文](platform-v1-privacy-policy.json)：与配套网站准备页的公开数据一致，生效日为空，线上发布地址尚未确认。
4. [脱敏核对依据](platform-v1-privacy-evidence.json)：用户确认、只读控制平面结果、单条主动生成的公开请求样本及官方文档来源。

配套网页为 [网站 PR #233](https://github.com/xdgf558/caption-ai-landing-site/pull/233)。本轮核对的 `src/data/station-cat-music-privacy.json` SHA-256 为 `2c49ea2e2fd354b23a8e11308c55ada2519b259d1ad5fe7376c54b8e6441c67d`；其公开字段与本 PR 的四语政策数据一致。双方均未发布，任一方正文调整后应重新比较。

日志中的四位经纬度只说明保存的数值形式，不验证实际定位精度。问卷中的精确位置是待复核的保守披露建议，不能解读为 App 使用 GPS。姓名、邮件地址和支持内容按用户主动联系时提供的范围披露；本机收藏、搜索和最近查看不因服务器请求日志的存在而变成远端同步数据。

没有导出其他访客日志、读取数据库行或访问支持邮箱；原始 IP、坐标、凭据和私人审核电话不进入仓库。3 天调用日志、7 天数据库恢复、一个月支持邮件和最长 30 天邮箱服务商备份各有独立范围，不是统一删除保证。

三个 JSON 文件可解析；四语正文的公开字段与网站数据一致，网页每语 8 节正文检查通过；`git diff --check` 通过。本批不改变产品代码，不重复执行 Xcode 或实体机测试。合并文档不授权政策部署、问卷发布、1.0 安装或上传、提交商店审核。
