2026-10-18 · 0.1.2（12）增补 · 待确认，未发布，未填写 App Store Connect 问卷。本稿对应公开作品平台版，不沿用旧网页播放器的匿名收听统计或原生账号规则。

## 已核对的数据流

| 数据/动作 | 当前客户端行为 | 提交前确认 |
| --- | --- | --- |
| 作品、推荐和封面请求 | 通过 HTTPS 请求公开目录、详情和图片；无账号 Bearer、Cookie 或自有设备标识。语言会随请求发送，作品详情 URL 含作品标识。 | 网站/CDN 是否记录 IP、请求路径、时间、User-Agent 等；日志保留、访问与删除规则。 |
| 搜索、收藏与偏好 | 搜索在当前目录本机过滤；收藏及偏好保存在本机，不接入远端个人同步。 | 不把本机保存描述为服务器收集；设备/系统备份行为须与实际文件策略一致。 |
| 最近查看 | 新增独立本机浏览记录，仅保存作品 ID、规范 slug 和查看时间，不含推广参数、外链或播放状态。最多 100 条；每次读取/写入清理超过 30 天的记录。关闭会清空；不上传。 | 名称仅复用服务端明确允许的限时 bookmark 资料；过期显示占位。记录及常用平台偏好按运行环境/账号隔离，排除系统备份。 |
| 封面缓存 | 150 MiB 磁盘、24 MiB 解码内存预算；遵循服务端有效期。缓存目录排除系统备份；用户可单独清理。 | 已下载图片不会因服务器撤回而被远程即时擦除；过期或版本变化会重新请求。 |
| 歌词、故事与短片 | 歌词和故事仅在当前详情页内存展示；字号偏好保存在本机。已发布短片在用户点击且重新核验后才通过有界 HTTPS Range 读取，初始静音；离开详情或进入后台会停止，不写视频磁盘缓存。短片海报沿用现有封面缓存规则。 | 网站/CDN 仍可看到这些资源请求；没有短片点击或观看分析事件，不能用请求次数推断完整观看。 |
| 外部平台与分享 | 用户点按后交由系统打开受控 HTTPS 链接；用户可通过系统分享作品网页。 | 第三方服务会按其自身规则处理网络、账号和播放信息；不承诺能在所有地区或设备播放。 |
| 历史版本资料 | 保留旧账号作用域、本机记录及旧缓存的现有保护规则。平台版不重新登录、上传或新增离线音频。 | 清理封面不等于删除旧账号或全部个人资料，不能承诺一键销户。 |
| 支持邮件 | 点击邮件链接，由邮件 App 处理用户主动发送的内容。 | 运营者对支持邮箱信息的使用、访问与保留规则。 |

源码没有集成广告/分析 SDK、IDFA 或跨应用跟踪调用，也不发送播放器收听事件。但这不能推导为“没有服务端访问记录”。配套网站仓库启用了 Workers observability；该配置不是当前日志实际字段或保留期限的审计证明。本轮没有读取用户请求日志。

Apple 将离开设备且能够保留超过实时服务请求所需时间的信息纳入其数据收集定义。填写问卷需要同时核对服务端实际处理；当前不预填「不收集任何数据」。[App Privacy Details](https://developer.apple.com/app-store/app-privacy-details/)

## Required Reason API 清单

`Resources/PrivacyInfo.xcprivacy` 声明不进行跟踪。`FileTimestamp / C617.1` 对应应用容器内缓存修改时间、回收和旧文件完整性检查；`UserDefaults / CA92.1` 对应本应用偏好。它只说明这些 API 的用途，不等于完整的 App Store 隐私标签，也不替代公开政策。[Apple Required Reason API](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitypereasons)

## 可用于政策的已确认正文

Station Cat Music 帮助你浏览 Station Cat 的公开音乐作品、阅读介绍、在本机收藏，并通过作品提供的链接前往音乐平台收听。当前版本不要求 Station Cat 账号，不销售订阅，不在 App 内提供完整音频播放或新的离线歌曲下载。

你还可以阅读已发布的歌词和创作故事；若作品有已发布短片，可点按观看，初始为静音。歌词和视频不会作为离线内容保存在设备，离开页面或进入后台会停止短片。歌词字号是本机设置。

为了取得作品信息、歌词、短片和封面，App 会连接 Station Cat 网站，并发送获取相应内容所需的语言和作品信息。网络服务同时会接收到建立连接所必需的网络信息。有关这些请求信息的具体记录和保留方式，需在发布本政策前补充确认。

收藏及本机偏好保存在你的设备。新增的“最近查看”与旧播放历史分开，仅记录你在 App 中成功打开的作品；最多保存最近 30 天的 100 条记录，并在下次读取或写入时清理过期项。你可以在“最近查看”二级页关闭或清空记录。常用音乐平台只影响已核验入口的排序，不会记录第三方实际播放。封面在服务器允许的有效期内可以复用，减少重复下载；你可以在「我的 → 设置与帮助 → 隐私与存储」查看和清理封面缓存。封面缓存不提供离线音乐播放，也不会在清理时删除收藏或旧版本保存的歌曲。旧版本留下的数据仍按原有隔离范围保留，并可使用 App 中相应的管理入口处理。

当你选择打开音乐平台或分享链接时，系统会把相应链接交给你选择的应用或服务。该服务的数据处理、登录和收听条件适用其自身规则。Station Cat Music 不会因打开链接而获得该平台的账号凭据、购买记录或完整播放记录。

你可以通过 brodstem@protonmail.com 联系支持。请只提供解决问题所需的信息，不要发送密码、验证码或付款卡号。

运营主体/联系人法定名称与适用地区；网站及 CDN 请求日志的真实字段、用途、访问范围、保留和删除/备份规则；支持邮件的保留规则；适用的数据请求渠道和生效日期。上述信息确定后，将完整政策发布到稳定的公开 HTTPS 地址，完成四语版本并核对 App 内入口和商店 Privacy Policy URL，再填写隐私问卷。

现有 `/zh-hans/privacy/` 等网站政策主要描述网页匿名播放统计，不足以直接充当这份 App 的完整政策。本批只修正 App 原先已失效的音乐页锚点，不宣称已经完成公开政策发布。
