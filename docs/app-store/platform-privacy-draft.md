## 服务端核对结果（2026-10-20）

`caption-ai-landing-site` 当前部署版本为 `00215fae-e046-4bcc-8813-7e863c4b2f8b`，100% 流量，部署时间为 2026-10-18 12:07 UTC。`script-settings` 返回 observability、logs、persist、invocation_logs 均启用，采样率 1，`redact_query_string: false`；Worker 的 Logpush 关闭、Tail consumer 数量为 0。仪表板确认日志与调用日志已开启、采样为 100%、没有日志导出目的地、Traces 未启用。平台限额仍可能触发额外采样，不能把配置的 100% 写成每个请求都必然留存。

登录后查看的字段目录包含 `request.url`、`request.headers.cf-connecting-ip`、`x-real-ip`、`user-agent`、`accept-language`，以及 `request.cf.country/city/region/latitude/longitude` 等网络地域字段。随后对本次带唯一 User-Agent 的公开目录 GET 进行限定查询，匹配到 1 条成功日志，核对了原始 IP 字段、国家/城市/地区、经纬度、响应状态、CPU 与墙钟耗时。仓库只保存字段存在性和经纬度小数位数（均为 4），不保存原始 IP 或坐标值。IP 推断与设备 GPS 权限不是一回事，也不证明四位坐标准确定位了真实设备。账号成员页显示 1 名已启用成员；这不是对全部 API 凭据、历史访问或服务商内部访问的审计。

公开 API 会按请求类别、分钟窗口和来源 IP 计算 HMAC-SHA256，在 `music_rate_sources` 保存摘要、窗口、类别和次数；它不是原始 IP 字符串，但也不应未经论证就称为匿名数据。相关代码不把原始请求、摘要或 SQL 写入自身的限流错误日志。窗口超过 10 分钟后，在后续请求中分批清理，每次最多 100 条来源记录、30 条汇总窗口。因此 **10 分钟是清理资格阈值，不是持久化数据的最长保留承诺**；没有后续流量或存在积压时可更久。数据库恢复历史和手动备份还须另外计入。

公开接口还读取 Cloudflare 提供的国家代码用于选择平台入口，不请求设备 GPS。本机收藏、最近查看及常用平台偏好不会因此上传。作品标识、语言和请求时间仍可能出现在服务器调用日志中；客户端丢弃推广参数不等于网站/CDN 从未接收到外部链接中的查询参数。

套餐读取接口此前返回 403；用户完成登录后，仪表板已明确显示 **Workers Free 为当前套餐**，据此确认当前 Workers Logs 保留期为 **3 天**。音乐库 Time Travel 页面也直接显示可恢复过去 **7 天**。本轮没有增加凭据权限、升级套餐或执行恢复。`d1 info` 确认音乐库当前在 WNAM 区域、读副本关闭；这只是当前运行区域，不代表全部数据都位于同一地区。[Workers Logs](https://developers.cloudflare.com/workers/observability/logs/workers-logs/)、[D1 Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/)

这两个期限分别适用于 Workers Logs 和音乐 D1 的恢复历史，不能扩展成 Cloudflare 所有网络、安全或账户数据的统一期限。Cloudflare 的服务可能跨境处理网络信息，其独立网络处理由其政策说明。发布前应沿用当前事实，不宣称已审核所有服务商合同或完成每个地区的法律评估。[Cloudflare Privacy Policy](https://www.cloudflare.com/privacypolicy/)

本机只保留脱敏的控制平面摘要；签名材料、认证数据、原始命令输出和截图原件继续放在忽略目录。这里没有修改日志开关、保留策略、数据库或生产原生服务。

运营者于 2026-10-20 确认：除 Cloudflare 自带日志及恢复功能外，不另外导出或备份访问日志；支持邮箱仅由本人访问，支持邮件在问题解决后保留一个月。Proton 的政策另说明邮件存储于瑞士、德国或挪威，加密备份最多保留 30 天。这个服务商备份窗口与运营者的邮箱删除时间分别告知；本次没有访问邮箱或审计实际删除执行。[Proton Mail Privacy Policy](https://proton.me/mail/privacy-policy)

运营者：浩 叶（中国）。支持及隐私联系邮箱：brodstem@protonmail.com。

Station Cat Music 帮助你浏览 Station Cat 的公开音乐作品、阅读介绍、在本机收藏，并通过作品提供的链接前往音乐平台收听。当前版本不要求 Station Cat 账号，不销售订阅，不在 App 内提供完整音频播放或新的离线歌曲下载。

你还可以阅读已发布的歌词和创作故事；若作品有已发布短片，可点按观看，初始为静音。歌词和视频不会作为离线内容保存在设备，离开页面或进入后台会停止短片。歌词字号是本机设置。

为了取得作品信息、歌词、短片和封面，App 会连接 Station Cat 网站，并发送获取相应内容所需的语言和作品信息。网络服务可记录 IP、请求地址、时间、User-Agent、响应状态、性能及 IP 推断的地域信息，用于提供内容、故障排查和防止滥用。国家代码还用于选择可用的音乐平台入口，App 不请求设备 GPS。当前 Workers 调用日志保留 3 天。服务端另将来源地址转换为按分钟及类别变化的安全摘要和次数，超过 10 分钟后由后续请求分批清理，因此不承诺每条摘要都在 10 分钟内删除；音乐数据库恢复历史另保留 7 天。

收藏及本机偏好保存在你的设备。新增的“最近查看”与旧播放历史分开，仅记录你在 App 中成功打开的作品；最多保存最近 30 天的 100 条记录，并在下次读取或写入时清理过期项。你可以在“最近查看”二级页关闭或清空记录。常用音乐平台只影响已核验入口的排序，不会记录第三方实际播放。封面在服务器允许的有效期内可以复用，减少重复下载；你可以在「我的 → 设置与帮助 → 隐私与存储」查看和清理封面缓存。封面缓存不提供离线音乐播放，也不会在清理时删除收藏或旧版本保存的歌曲。旧版本留下的数据仍按原有隔离范围保留，并可使用 App 中相应的管理入口处理。

当你选择打开音乐平台或分享链接时，系统会把相应链接交给你选择的应用或服务。该服务的数据处理、登录和收听条件适用其自身规则。Station Cat Music 不会因打开链接而获得该平台的账号凭据、购买记录或完整播放记录。

你可以通过 brodstem@protonmail.com 联系支持，或请求访问、更正、删除我们持有的与你相关的信息。支持邮箱仅由运营者本人访问，邮件内容用于处理你的问题，并在问题解决后保留一个月后删除。请只提供解决问题所需的信息，不要发送密码、验证码或付款卡号。除 Cloudflare 自带日志与恢复功能外，运营者不另行导出或备份访问日志。邮箱服务商的加密备份另有最多 30 天保留期，删除当前邮箱中的邮件不等于所有恢复副本立即消失。
