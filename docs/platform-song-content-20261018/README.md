# 第二批：歌曲内容 · 0.1.2（12）

2026-10-18。承接 0.1.1（11）的“我的”页、最近查看和常用平台；两批功能一并纳入本次 PR。用户选定第二张设计图 `selected-design.png`，并明确“暂时没有短片，留空”。本批为本地实现，没有发布网站、安装手机、分发签名或上传 TestFlight。

## 用户可见行为

歌曲详情采用紧凑封面与作品信息，优先展示用户常用的已核验平台，然后是歌词、短片、故事三个栏目。所有平台链接、收藏、分享、详情失败重试及系统拒绝打开后的复制入口继续使用现有路径。点开详情和切换栏目均不会请求完整歌曲或开始原生音乐播放。

歌词从已发布详情的受控 `lyricsUrl` 读取，支持 UTF-8 TXT 与 LRC 的纯文字阅读。LRC 时间标记不会被当作外部平台播放进度；段落保持原顺序。提供标准／大／更大字号、系统动态字号、全文展开收起和文本选择。仅字号偏好存入 UserDefaults；歌词、故事和短片列表不形成新的磁盘内容缓存。歌词与短片各自请求、各自重试，一个栏目失败不隐藏收听入口。切歌、换语言、关闭详情后的迟到内容不能覆盖当前页面。

故事显示服务器已发布的原文。没有歌词、故事或短片时显示对应的暂无内容；404/410 与网络失败不会伪装成成功空列表。短片目录最多展示三条，核对歌曲、资源地址和发布信息；最多读取五页以处理后端过滤后仍有 cursor 的空页。

短片能力为后续素材接入准备：只有用户点击时才重新核验发布记录，随后启动独立前台 AVPlayer，初始静音。视频通过无凭据、无 Cookie、无磁盘缓存、禁止重定向的有界 HEAD／Range 通道读取，校验 MIME、ETag、长度和 Content-Range。离开栏目、关闭详情、外跳或进入后台停止播放；不接入旧音乐队列、播放授权、Now Playing、后台音频、画中画或个人同步。短片海报沿用现有图片加载与缓存策略。

## 真实内容与预览的区别

本轮只读核对《屏幕朝下》的公开详情：有封面、网易云入口和《后来，我们开始设防》归属，但 `lyricsUrl` 为 null，`story` 为空，短片列表为空。因此新界面不会在正式模式伪造已发布内容。网站现有 `/tracks/{slug}`、`/tracks/{slug}/clips` 和 `/assets/{id}` 接口已提供本批所需字段，本轮没有改网站运行时或生产数据。

视觉预览明确使用 `--platform-music-fixture` 与 `STATION_PLATFORM_FIXTURE=song-content`，仅 Mock 的 DEBUG 模拟器分支能够选择它。预览封面及歌词来自用户移动硬盘上《屏幕朝下》的成品文件；故事明确标记为“界面验证示例”；短片为空。模拟器单元测试临时生成的 64 px 静音 MP4 仅用于验证 AVPlayer，不是歌曲短片，不会打包或发布。正式歌曲歌词和故事仍需按各曲真实素材发布；本批界面完成不等于这些数据已经上线。
