# Station Cat 电台界面改版 · 2026-11-03

候选版本为 **1.0.8（21）**。本批根据用户提供的 `iOS应用UI重设计.zip` 在现有 SwiftUI 工程中实现界面与交互，并同步简体中文、繁体中文、English、日语文案及更新说明。交付包中的 HTML、示例作品、节目时间和示例笔记是设计参考，不作为正式内容或线上验证证据。

## 界面与入口

平台版底部改为四个一级入口：电台、唱片架、笔记、我的。电台用拖动刻度、上一首/下一首及 VoiceOver 调整动作浏览推荐作品；FM 频率是客户端视觉位置，不是真实广播、播出时间或播放状态。歌曲和专辑仍使用现有接口返回的公开资料，缺失内容显示相应状态，不补造节目、歌词、故事、专辑链接或用户笔记。

唱片架保留全部、单曲、专辑分类与搜索；专辑使用独立封面及实际介绍，歌曲详情采用纸张 Sheet、歌词/短片/故事分段和底部固定收听操作。收听继续复用已核验的平台入口及现有网易云官方网页能力，不新增原生完整音源、订阅或后台播放。没有专辑级链接时，不用第一首歌曲的链接冒充整张专辑入口。短片仍由用户点击后才连接对应服务。

“我的”展示实际收藏与笔记数量、收藏封面、最近查看小票和常用平台。最近查看仍是浏览记录，不能证明第三方平台实际播放；原有关闭、清空确认、隐私、帮助及旧资料管理入口保留。

一级页面只在选中时创建，切换后不在隐藏页面继续执行列表过滤与排序。调频位置、唱片架搜索与分类、笔记搜索与主题过滤保留在当前 AppModel 中，切回仍可继续使用；切换账号会清除笔记搜索与过滤，避免带入另一作用域。专辑导航继续使用已有的公开专辑 ID。普通列表滚动位置和设置子页不作跨 Tab 保留，切回相应入口会回到一级页；全屏笔记编辑器覆盖底部导航，已输入草稿继续沿用保存、放弃确认及失效上下文保护。

“我的”直接提供语言、隐私与本机数据、关于帮助三个设置入口，不再重复显示第二组相同设置。只有存在旧播放记录、离线资料或原生账号资料时才显示旧资料管理入口；资料内容和删除能力保留。共享弹层继承所选外观，旧原生模式仍由根视图统一使用深色。

## 外观、图标与字体

采用暖纸色、朱红强调色和衬线排版，支持 `system`（跟随系统）、`paper`（日间纸张）、`night`（深夜电台）三态外观，使用本机 `radioAppearance` 偏好。图标和 App 内品牌图使用交付包中的猫耳唱片版本，包含默认与深色图像；没有据此声称完成 Icon Composer 分层或 tinted 图标制作。

简中和英文的标题、歌词等衬线文本使用未修改、未裁字的 **Noto Serif SC 可变字体单文件**：`Resources/Fonts/NotoSerifSC.ttf`，25,125,512 字节（约 25.1 MB）。这会增加安装包体积，不把它描述为已经裁剪或压缩的字体。字重通过字体的 `wght` 轴设置，字号支持 Dynamic Type；UI 正文与等宽标签采用系统字体。随附 `Resources/Fonts/OFL.txt`、`METADATA.pb` 和 `SOURCE.json` 保存 SIL Open Font License 1.1、固定上游提交和文件摘要。繁中优先系统 Songti TC，缺少该字体时使用语言感知的原生 TC 字体；本机 iOS 26.4 实测回退为非衬线的 PingFang TC，不以 SC 字形冒充繁中。日文使用可用的 Hiragino Mincho ProN。不可变字体通过限额 96 项的 NSCache 复用，键包含实际缩放字号、字重和区域，具体来源、取舍及探测边界见 `Resources/Fonts/README.md`。

## 本机笔记兼容

笔记仍采用现有账号/运行环境隔离、本机原子文件、容量限制、设备保护和排除系统备份策略，标题与正文不上传、不跨设备同步。新字段 `quote: String?` 沿用 schema 1；旧 JSON 没有该字段时解码为 `nil`，读取旧笔记不会重写其内容。此兼容范围是新版读取旧资料，不保证旧安装包能保留它不认识的新字段。

歌词摘录必须由用户主动选择单行、进入编辑器并确认保存；仅浏览歌曲或打开编辑器不会自动持久化歌词。摘录上限统一按 Swift `Character` 计为 200 个，详情选择、文件保存与重开读取共用同一校验；允许同一 emoji 字素内的 ZWJ 组合，继续拒绝换行、双向覆盖及隐藏控制字符，不静默删改引文。摘录保留作品 ID 与 slug，移除或更换关联作品时清除摘录。标题只保存用户输入去除首尾空白后的文字；空标题保持为空，由列表按当前语言显示无题，摘录不复制到标题。既有标题不作推测性迁移或清理，即使其文字与旧的无题标签或摘录相同。用户自行输入的超长标题仍由原有校验拒绝，不静默截断。保存失败保留草稿与原文件，清空或切换作用域后，旧编辑上下文不能恢复已清除的笔记。笔记搜索和主题选择在切换主标签时保留，切换作用域时重置。详细隐私差异见 `radio-notebook-privacy-delta.md`。
