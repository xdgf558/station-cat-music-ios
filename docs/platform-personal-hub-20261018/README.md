## 产品范围

一级页使用现有 Quiet Orbit 背景、品牌图标、原生字体和 SF Symbols。收藏卡片为主入口，下方展示最近查看两项，以及常用音乐平台、设置与帮助。封面来自当前已载入的收藏作品；没有可用封面时不伪造收藏或展示数量。

二级页包括完整收藏、最近查看、平台偏好、设置与帮助。既有语言、封面缓存、支持和版本记录从设置进入。平台模式的账号入口仅在实际可用或有相应状态时出现；旧离线文件仅在检测到文件时出现。旧播放记录按原含义保留在历史资料，不改成浏览记录。旧原生模式保留原有入口。

本批不增加歌词、视频、提醒或分析事件，不变更网站接口、生产开关、支付、原生音频和远端个人同步。没有自动安装手机、上传 TestFlight 或发布网站。

## 本机存储与隐私边界

- `PlatformPersonal-v1` 位于 Application Support，原子写入、首次解锁文件保护、排除系统备份，按运行环境和账号隔离。
- 浏览关系只包含作品 ID、规范 slug、查看时间。最多 100 条；每次读取/写入回收超过 30 天的记录。应用没有运行时，不声称后台已执行删除。
- 只有用户导航后、身份校验成功且仍在当前作用域的详情才产生查看记录。推荐预取、目录刷新、语言重载和外链点击不构成新的一次查看。
- 清空或关闭/再开启使用新的持久化 epoch；在途旧详情无法跨越此边界写回。文件损坏失败关闭，不自行重置隐私开关。状态修订号避免迟到快照覆盖新的本机设置。
- 文字展示只复用已有 `/bookmark` 明确授权的限时缓存。原目录/详情响应仍不持久化。封面、平台 URL、权限、推广参数不写入浏览日志。过期文字显示占位条目；点开仍须重新请求并验证详情。
- 浏览记录、收藏关系和旧播放历史为独立数据。关闭浏览或清空封面不会清空收藏、旧音频、旧播放记录。
- 常用平台默认跟随网站排序。选中后仅把已有的、经校验的平台链接稳定置前；同平台与其他链接各自保留原顺序。没有对应链接时给出说明，不生成替代地址。

详细数据流已同步至 `docs/app-store/platform-privacy-draft.md`，这仍是准备稿，不代表已填写商店问卷或发布隐私政策。
