## 五项视觉核对

| 表面 | 实际检查与结论 |
| --- | --- |
| 字体、层级 | 使用系统动态字体及中、英、日原生字形。首页标题、收藏标题、最近查看、操作行层次明确；大字号标题允许换行，没有以缩小字号隐藏文字。 |

| 颜色 | 延续原有深海军蓝背景、紫色强调、浅白主文字、灰蓝次文字。原生卡片渐变比概念图的随机纹理更克制，属于可接受的实现差异；没有再使用纯色大平面削弱收藏主区。 |
| 图片 | 继续使用已批准的品牌及 OrbitBackground 资源。在线封面来自现有专辑夹具的真实图片资源，正式运行使用已加载的当前收藏作品；不使用源图里示意的歌曲和数量替代真实数据。无许可的离线封面留空或显示明确占位，不能以截图伪造持久缓存。 |
| 文案、状态 | 简繁英日齐全；实际数量为 2，初始平台为“跟随网站排序”。“最近查看”与“最近播放”区分；隐私说明与存储实现对应。二级偏好页、浏览页与更新记录均有原生返回导航。 |
