# R1 第二批：隔离销户个人阶段和本机账号文件回收

首版继续不售卖订阅。原生认证、音乐、同步开关保持 NO，origin 保持空；没有生产部署、真实销户、购买或 App 上传。

## iOS 修改

资料库设置增加四语“清理其他账号的本机资料”及确认说明。仅删除已同步、无未发送操作、非当前账号的真实资料文件。游客、其他运行环境、正在同步的账号、未解决冲突/本机隐私保护状态、未同步隐私指令、schema 1/未知格式、损坏文件、符号链接均保留。不会删除服务器账号或更改 Keychain。

文件清理和本机资料写入共用 ScopedLibrary actor。读取、检查和删除之间没有挂起点。当前作用域在同一 actor 登记；确认后已切换账号时拒绝执行。账号切换先登记受保护作用域，再发布新 UI 作用域。删除后移除已解码副本；以后重新登录该账号仍可从服务器取得新基线。清理部分失败时明确报告未完成，可以重试。

新增 7 个测试覆盖磁盘重开、实际文件数量减少、同步等待期间保护、符号链接目标与损坏文件保留、关闭历史未发送操作保留、过期确认与 actor 作用域不一致拒绝执行。

## 网站配套

网站独立分支 codex/r1-deletion-lifecycle 提供仅由合成 D1 测试调用的分阶段执行器与可恢复租约。评论匿名保留、凭据/私人数据清理、财务独立待办和残留校验已实现；公共回执仍停在 attention_required，完整销户没有启用。隔离 SQL 未进入正式迁移目录。

同步回执有版本化紧凑编码和兼容读取，合成夹具验证原幂等回执、墓碑及隐私 epoch 保留、跨账号隔离和还原旧 JSON。生产写入仍为旧 JSON，无自动压缩。原 ID/摘要/版本不能作为普通缓存删除。

本批 iOS 接口格式未改，认证/媒体探针仍固定先前已审查网站 08d8918。新的网站清理/压缩试验通过网站独立真实 D1 测试验证；未声称由当前固定后端的 Swift 探针验收。

## 本机验证及限制

本机 Xcode 27 beta 6 / iOS 27 模拟器；不替代 CI 固定 Xcode 26.4.1 或实体 iPhone。已运行新增清理与现有隐私同步、配额测试，常规全套 Swift 与 UI 测试；专用长媒体和跨进程认证探针按常规套件设计跳过，不沿用旧证据宣称本轮执行。

R1 尚不能关闭：财务最小字段/年限、回执审计期限、支付平台/备份与软关联清理、恢复旧备份后的防复活均未完成。突破活跃账号条数上限或淘汰旧墓碑需要独立 generation 协议；本批只有不丢信息的压缩。真实 HTTPS/AASA、实体机和正式上架验收保持后续任务。

最终本机全套结果：128 项常规 Swift 测试通过，19 项专用探针按设计跳过；3 项 UI 测试通过。源码边界、四语一致性、工程/资源生成及 git diff --check 通过。见 [本机证据与源码哈希](R1-local-evidence.json)。本分支尚未执行远端固定工具链 CI。
