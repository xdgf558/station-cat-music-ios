# v1.0 发布目标与剩余任务

2026-09-20：用户确认优先上架不售卖订阅的 v1.0。M6 苹果订阅后端、M7 StoreKit 购买与 v1.1 送审暂缓；M8 可选优化不纳入首版。

## 范围与基线

首版提供原生音乐浏览、授权播放、专辑与歌词、队列和系统播放控制、统一账号、已有会员音乐权益、收藏与最近播放及隐私设置。不加入订阅商品、价格、购买或恢复购买入口；不以积分充值或外部购买入口替代订阅。

网站 #177（审核 head a5c0ad0，合并 270043b3）与 iOS #7（审核 head 378262a，合并 ade57e2）已合并。最新 iOS head 的 push 35445860077 和 pull_request 35445862397 完整 CI 均通过。该结果仅证明隔离交付，不等于真实环境、实体机或上架验收。

R1 可以继续使用本地隔离服务和合成数据推进。用户已确认公开评论匿名保留、个人清理不被余额或争议阻塞且不自动退款/清零。财务保留期限、最小字段及平台备份策略仍须明确；不能将原草案的 approved/executionEnabled 改为 true 当作已经批准。未完成必要清理不得报告 completed。

R2 的隔离域名、Team ID 和 App ID 已于 2026-09-22 配置，隔离 HTTPS、原生网络/播放、真实系统浏览器登录回调与歌曲/专辑冷暖启动 Universal Link 均已通过模拟器验收；固定稳定 Xcode CI 与实体机仍未验收。具体证据和限制见 [R2 联调记录](R2-preparation.md)。R3 仍需要可用实体 iPhone。

## 发布边界

干净检出的原生认证、音乐、个人同步开关仍关闭，origin 为空。用户授权的本机 Staging 可通过忽略的 R2 配置显式连接独立测试 Worker；Production 没有该配置入口，仍保持关闭。既有网站生产状态不因本计划改变。不迁移生产库、不处理真实销户、不改支付、不上传或提交 App。

首次上架不要求先完成 M6/M7，但必须补齐 M2–M5 遗留的全部首版阻断项，尤其是完整销户与真实认证/媒体链路。具体审核要求在准备送审时重新核对 Apple 官方最新资料。
